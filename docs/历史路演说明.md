## 使用方式

1. 将本目录中的 `index.html` 与 `assets/` 文件夹一起上传到服务器。
2. 通过浏览器打开 `index.html`。
3. 建议使用 16:9 屏幕，并按 `F` 进入全屏。

不依赖外部字体、脚本或网络资源，可以直接静态托管。

## 演示控制

- `←` / `→`：上一页 / 下一页
- `Space`：下一页
- `F`：全屏
- `N`：显示或隐藏演讲备注
- `H`：快捷键帮助
- 鼠标滚轮、手机左右滑动也可以翻页
