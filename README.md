# 大劫卡西诺（Heisino Game）

横版 2.5D 多人搜打撤卡牌微信小游戏。玩家从赌场外围进入 5×5 区域，在 12 个回合内搜索物资、处理玩家遭遇，并从唯一撤离点安全离场。

## 当前状态

当前里程碑：M2 完整本地纵切测试包。

微信开发者工具内已经可以从头体验以下流程：

```text
加载页 → 开始游戏 → 匹配 → 移动选择
→ 搜索或自动战斗 → 回合结果 → 撤离/失败结算
```

已完成：

- 使用已确认的红金赌场、海岛地图、昼夜角色视觉制作高保真 Canvas 界面。
- 开始页、匹配页、匹配成功倒计时、游戏 HUD 和结算页。
- 匹配最长等待 5 分钟、玩家取消和空房销毁规则模型。
- 测试包“单人立即开始”入口，以及本地模拟补齐两名玩家的标准匹配演示。
- 5×5 同步移动、隐藏选择、轨迹公布、中央金库第 6 回合开放。
- 单人搜索、两段式物资交互、背包、拖拽丢弃和掉落保留。
- 两人自动战斗、三人战斗/搜索分流、武器耐久和失败掉落。
- 第 10 回合开始的警报圈、唯一撤离点、消耗一回合撤离和终局结算。
- 匹配及核心规则自动化测试。

当前不包含：

- CloudBase 权威房间服务、真实三人联网和断线恢复。
- 玩家手动掷骰、骰子分配和技能预判操作；测试包暂时自动结算战斗。
- PvE、敌人 AI、正式账号资产持久化。
- 音效和背景音乐；当前版本按要求全局静音。

## 测试包临时规则

- “开始匹配”会在本机依次模拟两名玩家加入，用来验证完整流程，不代表正式线上匹配。
- “单人测试·立即开始”会直接补齐两个机器人，仅在开发测试包保留。
- 机器人负责随机移动和自动战斗，暂不自动拾取物资。
- 第 12 回合结束时仍未撤离即失败；第 12 回合才发起撤离将来不及完成。
- 警报圈在回合开始首先结算。若伤害使 HP 归零，即使上一回合已呼叫撤离也会先战败。

完整真人验收步骤见 [M2完整流程测试包说明](docs/M2完整流程测试包说明.md)。

完整产品流程、节点规则、决策台账与文档变更历史见 [游戏产品流程图](docs/游戏产品流程图.md)。该文档作为后续产品修改与开发实现的流程单一事实源。

## 已冻结规则基线

- 每局 3 人，最多 12 个全局回合，每回合 55 秒。
- 每回合可停留或移动到上下左右相邻节点；所有人选择完成后统一结算。
- 选择阶段隐藏其他玩家人数与目的地，结算后显示移动轨迹。
- 第 1–5 回合中央金库锁定，第 6 回合开放。
- 两人同节点进入战斗；三人同节点随机两人战斗、一人搜索，房间物资随机分半。
- 搜索物品第一次点击显示、第二次点击拾取；满包不能拾取。
- 第 10–12 回合开始时，存活玩家先扣 10 HP；战斗过程不受警报圈影响。
- 撤离点为 `(4,4)`，到达后呼叫接应，并消耗 1 个完整回合完成撤离。

## 技术结构

```text
client/
  assets/                    # 已授权的本地视觉参考资源
  data/                      # 客户端卡牌投影
  js/core/                   # 与画面解耦的规则、战斗、匹配模型
  js/main.js                 # 微信小游戏 Canvas 场景和交互

data/
  cards.json                 # 卡牌静态配置
  cards.schema.json          # 卡牌配置 Schema
  item-instance.schema.json  # 运行时物品实例 Schema

docs/
  M1规则原型说明.md
  M2完整流程测试包说明.md
  游戏产品流程图.md
  卡牌数据结构.md

tests/                       # Node.js 自动化测试
tools/                       # 配置校验和开发辅助工具
```

客户端目前采用微信小游戏原生 Canvas + CommonJS JavaScript。规则引擎和表现层分离，后续可继续原生开发，也可迁移至 Cocos Creator + TypeScript。正式联网阶段计划使用腾讯云 CloudBase 数据库、云托管和 WebSocket，由服务端裁决随机数、移动、战斗、掉落和最终结算。

## 本地运行

1. 打开微信开发者工具，选择“小游戏”。
2. 导入仓库中的 `client/` 目录。
3. 使用横屏模拟器编译。
4. 从开始页进入匹配；可等待本地模拟匹配，或点击“单人测试·立即开始”。
5. 按 [M2 验收清单](docs/M2完整流程测试包说明.md#4-真人验收清单) 完成一轮测试。

自动化检查：

```bash
npm run check
```
