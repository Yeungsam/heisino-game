# 大劫卡西诺（Heisino Game）

横版 2.5D 搜打撤卡牌微信小游戏。玩家从离岸码头配置战备，进入 5×5 赌场地图搜索、战斗，并从唯一撤离点带出物品。

## 当前可玩流程

```text
加载 → 微信登录 → 首次建号（默认头像/自填昵称，微信内容审核）
→ 码头主页（商店 / 仓库 / 开始游戏）→ 行动战备 → 码头大厅
→ 单人模式，或创建/加入多人房间并由房主开局
→ 移动选择 → 轨迹回放（支持的多人房间）→ 房间搜索 / 互动战斗
→ 下一大回合 → 自动撤离 / 战败 / 放弃 / 断线超时结算（仅成功撤离返仓）→ 返回码头
```

当前能力与边界：

| 模块 | 当前实现 |
|---|---|
| 账号与资产 | 每次冷启动验证微信身份；昵称格式及微信审核；首次礼包仅发一次；服务端事务处理扣仓、返仓、金币与流水；断网不降级为本地写资产 |
| 战备与仓库 | 战备最多 4 张、仅武器/防具/技能，武器和防具各限 1 件，可空装；仓库按同卡每格 99 张显示；新局背包 10 格、一格一件 |
| 单人 | 单人独立出发，合格房间可遭遇守卫；不依赖补齐机器人玩家 |
| 多人 | 2–3 名真人、房主开局、等待房有效期 10 分钟、退出不扣仓、房主转让、开局版本校验及全员原子扣仓；客户端轮询同步 |
| 地图与搜索 | 25 格、相邻移动或停留、隐藏选择、多人轨迹；第 6 回合开金库；房型权重与随机数量；50 秒搜索、每 0.5 秒揭示一件、拾取/丢弃及地图背包 |
| 战斗 | 最多 3 个小回合；真人主动掷 3D6、自由分配攻防、准备/取消；每小回合 15 秒操作、2 秒碰撞；战后胜负展示和 20 秒战利品窗口；武器、防具倍率生效，无耐久 |
| 守卫 | 多人独自移动到普通房间或开放金库时有 30% 概率遭遇；满血开始，每小回合两骰一攻一防；单人判定及旧局兼容见产品规则 |
| 撤离与恢复 | 第 12 回合起每回合扣 5 HP；完成当轮行动后存活于 `(4,4)` 自动撤离；中断不足 10 分钟恢复、满 10 分钟个人失败；多人共享时钟不因一人离线暂停 |
| 商店与美术 | 收购四类卡牌，按售价 120% 出售 A/B 级武器、防具、技能共 16 种；支持多卡整单买卖、重试幂等和旧报价拒绝；51 张有效卡牌使用 50 张新版卡面 |

当前未实现或暂缓：技能卡可拖用并消耗，但没有数值效果；可选微信头像授权待验收、建号后换头像入口待定；角色选择、新剧情及其他策划扩展待定。当前游戏全局静音，音效/BGM 和新手引导关已于 2026-11-23 纳入待实施需求。旧 `STANDARD` / `SINGLE_TEST` 机器人对局和独立 `/api/search` 保留兼容能力，不代表当前客户端入口。

## 技术结构

```text
client/                     微信小游戏 Canvas + CommonJS 客户端、规则与分包美术
  js/main.js                场景、绘制、交互与账号服务接入
  js/core/                  规则、背包、地图、物资库和旧匹配模型
  js/api/                   账号、卡牌与兼容搜索接口
  data/cards.js             随包卡牌投影
  subpackages/              房间、搜索及战斗美术

data/                       卡牌配置、售价、Schema、OCR 审计来源
functions/heisino-account/   微信身份、资产、商店、单人及多人对局权威服务
functions/heisino-cards/     卡牌目录与详情 Web 云函数
functions/heisino-game/      独立搜索兼容 Web 云函数与 CloudBase 事务存储
server/                     本地联调 HTTP 服务与卡面静态资源
tests/                      规则、接口、事务、Canvas 触控与资源自动化
scripts/                    构建、回归、发布和公网验证脚本
docs/                       当前规则、接口、进度及历史验收
cloudbaserc.json             CloudBase 环境与函数配置
```

客户端优先使用随包卡库，远程目录后台更新；API 和卡面资源域名分别配置。卡牌大图按需加载，不进入小游戏主包。搜索卡背位于本地分包。账号和正式对局均由 `/api/account` 推进，独立搜索契约见[搜索回合接口契约](docs/搜索回合接口契约.md)。

## 开发与验证

项目回归使用 **Node.js 22 或更高版本**（`package.json` 的最低运行声明不代替此要求）。

```bash
npm run account:build
npm run server
```

本地服务默认端口 3000，账号和搜索使用内存存储，重启清空；真实微信身份和昵称审核依赖服务端环境配置。客户端默认连接 CloudBase；本地联调需自行在 `client/js/config.js` 指向开发机地址。不得提交密钥或关闭合法域名校验作为交付状态。

在微信开发者工具以小游戏导入 `client/`，保持合法域名校验开启，编译后从「开始游戏 → 行动战备 → 前往码头」进入单人或多人。手机需生成新的预览，历史二维码均已过期。

```bash
npm run check
npm run test:regression -- --rounds 5
```

功能变更时同步更新回归矩阵，并运行 `npm run test:regression -- --update-cases`，将索引与功能、测试一并提交。GitHub Actions 对推送和 PR 执行一轮、手动触发执行五轮。真机布局、微信原生交互、多机画面和帧率均不由自动化代替。

公网冒烟按变更选择：

```bash
npm run verify:account:production
npm run verify:shop:production
npm run verify:cards:production
npm run verify:search:production
```

服务端或云函数共享规则/数据变化时，必须按[发布流程](docs/CloudBase发布与验收.md)完成五轮回归、受影响函数部署、真实公网业务响应与权限验证。本次文档整理没有新增服务端发布。
